### Projects

**ADIS** — Air defense intercept simulation  
SIM streams target data over UDP at 10 Hz; GCS renders it on a live tactical radar and sends intercept commands over TCP. Custom 12-byte packet header, heartbeat-based link monitoring.  
<sub>`C# WPF` `C++ DLL` `P/Invoke` `UDP/TCP`</sub>

**[Radar Simulator](https://github.com/peyoon/-Project-SIMSW)** — Radar simulation tool  
Coordinate conversion (DMS ↔ Decimal, Degree ↔ Mil), INI-based settings, data sharing across windows.  
<sub>`C# WPF`</sub>

**Gamma Spectrum HMI** — Nuclide identification UI  
CNN exported to ONNX and run in C#, with a live spectrum chart, per-nuclide probabilities, and Python ↔ C# preprocessing checks.  
<sub>`C# WPF` `ONNX Runtime` `PyTorch`</sub>

**[Club Management System](https://github.com/peyoon/-Project-Club-management-system)** — Club schedule manager  
Create, browse, and manage club events.  
<sub>`C# WPF`</sub>
